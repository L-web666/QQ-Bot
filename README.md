## 安装与使用  
1.访问QQ开放平台（ https://q.qq.com/#/ ）注册并登录账号  
2.在页面左侧点击“机器人”，再点击页面中间的“去创建或管理我的QQ机器人  
3.在页面右上角点击“创建机器人”，并按提示创建机器人账号  
4.在“设置AI服务”中点击页面右上角的“稍后连接”  
5.在当前页面选择你所创建的机器人  
6.选择“开发设置”，记下右侧的AppID和AppSecret  
7.下载Release中的
